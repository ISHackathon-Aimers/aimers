잘된 점

- 원문과 정리본을 분리하고 AI 미연결 상태를 명확히 안내한다.
- 새 기록 초안 보존, 삭제 확인, 입력 검증, 검색과 일괄 등록을 재활용할 수 있다.
- 데스크톱 사이드바와 모바일 하단 메뉴, 우측 상단 설정 진입이 이미 존재한다.

우선 문제

1. P1 경험 구체화 흐름 부재. app.js:115–125와 api.mjs:22–25는 문장 추출이다. 입력 → 부족한 정보 질문 → 답변 원문 보존 → 정리 검토 → 저장 흐름이 필요하다. 저학년 사용자가 한 줄에서 막히는 문제를 해결해야 한다. Suggested command: impeccable shape.
2. P1 주기와 성취 계산 불일치. api.mjs:11의 streak는 매일 단위이며 profile 주기를 사용하지 않는다. 10/19, 10/26, 11/2에 작성한 기록은 11/7에 0일로 계산된다. 새 사용자 예시 8개도 통계·스트릭·그룹 작성 여부에 포함된다. 시작일+주기에 따른 기간과 연속 완료 횟수를 계산하고 예시를 성취에서 분리해야 한다. Suggested command: impeccable harden.
3. P1 그룹 공유·프로필 권한 모델 부재. app.js:89–102는 그룹을 한 화면에 펼치며 프로필 기록 열람·공개 범위가 없다. 목록 → 그룹 상세 → 멤버 프로필을 구성하고 서버가 비공개 기록을 차단해야 한다. Suggested command: impeccable shape / harden.
4. P1 취업 활용 결과 부족. app.js:160의 면접 질문은 고정이며 연습 답변도 저장하지 않는다. app.js:168의 보고서는 학기 비교가 없고 :227의 추천은 키워드 매칭이다. 경험별 질문·추천 이유·학기간 변화와 근거 기록이 필요하다. Suggested command: impeccable shape / clarify.
5. P2 대시보드 우선순위·가독성. 동일 기록 추가 CTA가 반복되지만 주간 회고는 없다. 원래 기획에 없는 프리미엄 홍보가 공간을 차지한다. 데스크톱 성장 인사이트 메뉴가 어색하게 줄바꿈되며 모바일 제목도 단어 중간에 끊긴다. 보조 글씨가 9–11px로 작고 옅다. 기록 추가 / 회고 / 마감 정보를 상단에 두고 세 탭의 요약을 아래에 배치한다. Suggested command: impeccable layout / typeset.
