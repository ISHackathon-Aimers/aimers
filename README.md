# 에이머스

대학생의 경험을 기록하고 정리하는 웹 앱입니다. 흰 배경, 파란색 포인트, 간결한 카드와 반응형 레이아웃으로 구성했습니다.

## 실행

Node.js 24 이상이 필요합니다. 외부 패키지를 설치할 필요가 없습니다.

프로젝트 폴더의 start-aimers.cmd를 실행하면 서버를 시작할 수 있습니다. 실행 후 브라우저에서 http://127.0.0.1:4173 을 여세요.

또는 프로젝트 폴더에서 직접 실행합니다.

```powershell
node server.mjs
```

접속 주소는 http://127.0.0.1:4173 입니다.

서버는 127.0.0.1에서만 실행됩니다. 로컬 세션은 브라우저 쿠키로 식별합니다. 실제 회원 인증이 아니므로 외부에 직접 노출하지 마세요.

기록은 .data/aimers.sqlite에 저장됩니다. 서버를 다시 시작해도 유지됩니다. 브라우저의 쿠키를 삭제하면 기존 로컬 사용자로 다시 접속할 수 없습니다. 기록 내보내기를 통해 별도로 보관할 수 있습니다.

## 구현한 기능

- 대시보드, 기록 통계, 연속 작성일.
- 경험 작성, 수정, 삭제와 원문 별도 보존.
- 카테고리 추가, 검색, 필터, 정렬.
- 원문의 관련 문장을 추출하는 기본 정리.
- 지원 브라우저에서 한국어 음성 입력.
- JSON 파일 또는 줄 단위 텍스트로 지난 경험 일괄 등록.
- JSON 파일로 원문과 정리본 내보내기.
- 매일, 매주, 매월 기록 주기 설정과 앱 내부 안내.
- 그룹 생성, 초대 링크, 그룹 참여, 작성 현황.
- 멤버의 앱 알림함으로 콕 찌르기. 같은 사람에게 하루에 한 번만 보낼 수 있습니다.
- 기록을 활용한 면접 질문 템플릿, 학기별 보고서, 키워드 기반 자소서 경험 찾기 미리보기.

## 기능 범위

AI 모델은 아직 연결하지 않았습니다. 정리본은 작성한 문장을 추출하며, 사실이나 성과를 새로 만들어 넣지 않습니다. 면접 질문은 템플릿, 자소서 경험 찾기는 키워드 비교 방식입니다.

음성 입력은 브라우저의 SpeechRecognition을 사용합니다. 브라우저 지원, 마이크 권한과 네트워크 상태에 따라 작동 여부가 달라집니다. 실제 마이크 입력은 검증하지 않았습니다.

콕 찌르기는 앱 내부 알림입니다. 화면이 열려 있을 때 30초 주기로 갱신됩니다. 앱을 닫은 상태의 푸시, 이메일, SMS, 예약 발송은 연결하지 않았습니다.

프리미엄은 미리보기입니다. 결제, 유료 이용권과 공개 기록 공유 및 댓글은 구현하지 않았습니다.

그룹에는 이름, 작성 여부와 스트릭만 공유됩니다. 개인 기록 내용은 서버에서 사용자별로 분리합니다.

새로운 로컬 사용자에게 예시 기록 8개가 표시됩니다. 각 기록에 예시 표시가 있으며, 설정에서 예시만 지울 수 있습니다. 실제 작성 기록은 유지됩니다.

## 날짜 기준

날짜와 작성 주기는 한국 시간으로 계산합니다.

- 매주 기록은 월요일부터 일요일까지입니다.
- 매월 기록은 1일부터 말일까지입니다.
- 스트릭은 활동 날짜가 아니라 서버에 실제로 기록을 생성한 날짜를 기준으로 합니다.
- 같은 날 여러 기록을 남겨도 1일로 계산합니다.
- 지난 활동을 오늘 일괄 등록해도 과거 스트릭이 생성되지 않습니다.
- 1학기 보고서는 3월부터 8월, 2학기 보고서는 9월부터 다음 해 2월입니다.

## 파일 구조

- public/app.js: 화면, 이벤트와 사용자 흐름.
- public/style.css: 데스크톱과 모바일 스타일.
- src/api.mjs: 입력 검증, 사용자 권한, 기록과 그룹 API.
- server.mjs: 로컬 HTTP 서버와 SQLite 저장소.
- drizzle/0000_aimers.sql: 데이터베이스 스키마.
- scripts/build.mjs: Cloudflare Worker용 배포 파일 생성.
- tests/api.test.mjs: 사용자별 접근 제어와 핵심 기능 검사.

## 검증

```powershell
node --test tests/api.test.mjs
node scripts/build.mjs
node --check dist/server/index.js
```

자동 테스트는 기록 접근 권한, 원문 보존, 일괄 등록의 전체 검증, 초대 링크, 멤버별 상태, 알림과 발송 제한, 요청 출처와 인증 검증, 한국 시간 기준 스트릭을 확인합니다.

Windows 브라우저 접근 도구가 현재 URL을 확인하지 못해 자동 화면 검증을 중단했습니다. 실제 브라우저에서의 레이아웃, 키보드 흐름과 음성 입력은 검증되지 않았습니다.

## 호스팅 준비

.openai/hosting.json에 등록된 비공개 Sites ID가 있습니다. 새로 등록하지 말고 이 ID를 재사용하세요.

빌드하면 HTML, CSS, JavaScript를 포함한 단일 Worker가 dist/server/index.js에 생성됩니다. 호스팅 환경에서는 Sites의 인증 사용자 ID와 D1의 DB 바인딩을 사용합니다. 로컬 체험 세션을 운영 환경 인증으로 사용하지 않습니다.

배포에는 원격 소스 저장소 연결과 D1 마이그레이션 적용이 필요합니다. 실제 배포 상태는 별도로 확인해야 합니다. 비공개 사이트를 외부 친구와 공유하려면 사이트 접근 권한도 별도로 설정해야 합니다.
