2.해시태그는 빼는게 나을듯? 사용자 경험에 도움이 안될것 같으니 내부적으로만 분류해서 기록해두고 화면에는 안뜨게 해. (수정완료/검토대기)
3. 딥시크 API 키 DEEPSEEK_API_KEY 환경 변수 사용해서 AI 기능 완성 (수정완료/검토대기)
4. 서버/데이터베이스 기반 완성형 서비스로 해줘. 구글 로그인정도 달아두면 될듯. 로컬에서 돌리기 힘든 사이즈의 서버나 DB가 예상될 경우 사용자에게 알릴것. (수정완료/검토대기)
5. 프로필/ 설정 화면에서 화면 설정 칸은 삭제.  백엔드 확장에 따른 계정 등 여러 설정들 들어가야 할듯 (수정완료/검토대기)
6. 질문 구성 참고자료를 한국 기업들에서도 가져오고 페이지에 표시하지 마. 그리고 질문을 그대로 가져와서 돌려쓰지 말고 AI 기반이니까 퓨샷 느낌으로 생성하게 해 (수정완료/검토대기)

구현 확인 사항
- 1: 경험은 두 줄 입력으로 저장하고 상세 AI 문답은 기간별 회고에서 작성합니다.
- 2: 해시태그 입력과 화면 표시를 제거하고 내부 자동 분류는 DB에 보관합니다.
- 3: API 키는 Git에서 제외된 .env에 저장했습니다. 실제 DeepSeek 요약, 회고, 면접, 추천과 보고서 호출을 확인했습니다.
- 4: SQLite 기반 계정과 Google OAuth 연동을 구현했습니다. 이후 제공된 웹 OAuth JSON을 Git에서 제외된 로컬 환경에 연결했습니다. Google 콘솔의 콜백 주소 등록과 실계정 로그인 검증은 남아 있습니다. 대형 DB 서버는 필요하지 않습니다.
- 5: 화면 설정을 제거하고 연결된 계정, 로그아웃, 전체 세션 종료와 계정 삭제를 추가했습니다.
- 6: NAVER와 토스 공식 안내의 질문 방식을 내부 참고하며 직접 작성한 few-shot 예시로 생성합니다. 화면에는 참고 자료를 표시하지 않습니다.
