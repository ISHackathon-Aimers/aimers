## Anti-Slop 항목별 검토

아래 PASS는 **이번에 변경한 UI와 위에 기록한 검증 범위**에 대한 판정이다. 기존 앱의 모든 기능·장치·입력 조합을 다시 검증했다는 의미는 아니다. R-35의 전체 컨트롤 전수 실기기 검사와 전체 Taste 배포 게이트 완료를 주장하지 않는다.

## 적용하지 않은 검사와 경계

Taste의 홍보 페이지용 히어로, 화면 높이 고정, 사진·셰이더 지시는 실제 기록 앱의 작업 흐름과 맞지 않아 사용하지 않았다. Hallmark app-screen 절차가 구성 판단을 맡았다. 브라우저 사용은 상위 도구 규칙에 따라 CUA로 수행했고 별도 Playwright를 실행하는 `sloplint --render`와 Taste 전체 자동 브라우저 게이트는 실행하지 않았다. 이를 완주한 것으로 표시하지 않는다.

이번 실제 AI 호출은 경험 구체화 흐름을 확인했다. 면접·자소서·성장 서비스의 진입과 기존 자동 테스트는 확인했으나 각 서비스의 유료 AI 응답을 모두 재생성하지는 않았다. 사진 업로드 서버 검증은 자동 테스트에 포함되고, 실제 파일 선택과 음성 입력 장치는 이번 브라우저 범위 밖이다. 정식 인증·외부 예약 알림은 기존 운영 경계로 남는다.
