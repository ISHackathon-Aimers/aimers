# 회고와 면접 질문 설계

확인일: 2026-11-08

## 내부 참고 자료

- [NAVER Careers FAQ](https://recruit.navercorp.com/bbs/faq.do?lang=en): 직무 전문성과 조직 문화, 협업에 관한 대화를 구분한다. 이 구분을 개인 기여와 협업 관점에 반영한다.
- [토스커뮤니티 합류 여정](https://i18n.toss.im/career/joining-guide): 경험에서 만든 영향과 학습, 직접 개선한 과정을 구체화하도록 안내한다. 선택과 문제 해결의 근거를 묻는 데 반영한다.
- Google re:Work, Microsoft Careers와 Amazon Jobs의 공식 질문 안내도 구조화된 질문, 행동 근거, 가상 상황과 후속 질문의 참고 자료로 유지한다.

자료는 질문 방식을 이해하기 위한 내부 참고 자료다. 특정 회사의 실제 기출 데이터베이스가 아니다. 앱 화면에는 자료 목록과 링크를 표시하지 않는다.

## 생성 방식

코드의 questionExamples는 직접 작성한 가상 사례와 질문 예시다. 회사의 문항을 복사한 것이 아니다. 예시의 문장이나 사건을 사용자 결과에 섞지 않고, 구체적 원문에서 판단과 근거를 묻는 방식을 참고하도록 system 프롬프트에 넣는다.

questionPlan은 원문 내용과 이전 질문, 원하는 직무에 맞춰 서로 다른 관점을 고른다. 회고는 최대 3개, 면접 연습은 5개 질문을 생성한다. 같은 질문의 의미적 재표현까지 완전히 막을 수는 없지만 정확히 같은 문장과 중복 관점, 다른 사용자의 기록 ID와 원문에 없는 인용은 거절한다.

한국어 어미 변화 때문에 생성 질문에 원문의 anchor가 그대로 나타나지 않는 경우에는 서버가 실제 기록에 존재하는 anchor인지 먼저 검증한 뒤 질문에 인용 구절을 덧붙인다. 원문에 없는 구절을 새로 만들어 보완하지 않는다.

질문 검증 실패 시 한 번 다시 생성하고, 다시 실패하면 입력을 유지한 채 오류를 표시한다. 회고 원문과 질문 답변은 서버에 함께 저장하며 연결한 원본 기록은 유지한다. 면접 질문과 답변도 계정과 경험별로 최근 24개를 DB에 저장한다.

## 검증 범위

자동 테스트는 근거 검증, 소유권, 중복 검사, 원문 보존과 답변 저장을 확인한다. 실제 DeepSeek 요약, 회고 질문, 면접 질문, 추천과 보고서 호출을 확인했다. 생성 결과의 사실 정확성이나 실제 면접 적중률은 보장하지 않는다.
